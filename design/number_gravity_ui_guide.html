Gameplay

/play/:levelId

The whole game. Select a tile, read the physics, commit a one-cell move, watch gravity resolve.

Best UI — the spec's highest-impact screen
  • Ghost preview §10.1: translucent tiles show exactly where everything lands before committing — turns trial-and-error into planning.
  • Force telegraph: line thickness ∝ force, blue = pull / red = push, so physics is never hidden.
  • Moves vs. optimal always visible (4/6) — the star target is honest and ambient, no timer.
  • Undo / redo / hint and coin balance in one compact HUD; unlimited undo §10.2.
  • Big arrow bar for one-handed portrait play — 44px tap targets §10.5.

overlay on /play

05 · Cross-cutting

Principles that hold across all 16

These aren't per-screen — they're the connective tissue that makes the set feel like one game and one system.

One token set, two themes

Light and dark both derive from the same #2563EB / #DC2626 / #FBBF24 palette (Doc §11). Tiles keep their signal colors in either theme so the physics never becomes ambiguous.

Accessible by default

Color-blind mode adds shape/symbol to sign (+ vs −), not color alone. Reduce-motion, text size, haptics, and 44px minimum tap targets are settings, not afterthoughts (§10.5).

Text-light & global-ready

The board is numbers, tiles, and arrows — nearly language-free. All chrome strings live in ARB files with full RTL mirroring for the 12-locale launch (§21).

Readable physics everywhere

Force telegraph and ghost preview aren't just gameplay features — they're the promise that difficulty comes from planning, never hidden information (§10.1).

Fair economy, no dark patterns

Coins are convenience, never a gate. No fake countdowns, no guilt dialogs, no "Remove Ads." Rank is earned through play (§13, §22).

Forgiveness over friction

Unlimited undo, free restarts, no timer in campaign, and proactive stuck-detection. A thinking puzzle must reward experimentation (§10.2).
